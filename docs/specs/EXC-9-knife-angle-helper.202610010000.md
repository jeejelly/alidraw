# Knife and remarkable-angle helper
[sw-_file-verdict]: # '@validated(by="jeejelly", at=2026-10-01)'

[sw-_file-status]: # '@status(value=done, at=2026-10-01)'

Cut shapes along a line; held number keys lock remarkable angles, shared with rotation.

## Requirement: Knife
Tool C SHALL cut the selected closed shapes (or all) along a drawn segment into separate paths and return to selection.

## Requirement: Angle keys
Holding 0-9 SHALL lock 0/15/120/30/45/135/60/75/150/90 degrees for the knife and for rotation; angles SHALL read counter-clockwise, mod 180 for lines.
